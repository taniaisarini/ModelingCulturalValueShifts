GDELT Explorer

How often news-coded events of each kind were recorded in 29 countries, November 2003 to July 2023. Events are coded from news articles into CAMEO categories, so these series measure coverage, not what happened.

Source: GDELT events (v1 before 2015-02-18, v2 after; v2 reads many more sources, so counts and shares shift at that date). Share = events of the category divided by all events recorded for the country in the same window. Sub-event names are the official CAMEO event codes. The chart window moves across the series (a rolling window centred on each point, pooled over the window).
