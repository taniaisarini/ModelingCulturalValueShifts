World Values Survey — country and question pairs where the answers moved reliably between waves and by at least a minimum size for that kind of question.
How a change is decided

A change counts only if it passes both checks: it is reliable (a permutation test, corrected for the many questions tested per country, gives q < ) and it is large enough (the effect reaches the minimum for that question's format). Countries with fewer than respondents in either wave are skipped for that question.
